# Digital Twin Traffic Management System

This project is developed to simulate and analyze traffic flow using Digital Twin technology.  
The system helps monitor traffic conditions ,redirect to shortest route, traffic congestion range in each area with time visulaization charts and notifications are included  and improve smart traffic management .

## Project Description
The project creates a virtual representation of real-world traffic systems for analysis, monitoring, and visualization.

## Features
- Traffic Flow Monitoring
- Real-Time Traffic Simulation
- Data Visualization
- Smart Traffic Analysis
- Digital Twin Concept Implementation
- Notification included.

## Technologies Used
- HTML
- Tailwind css
- Firebase
- Google sheets
- Firebase authetication
- Make.com
- Rule based learning
- charts,graphs,heatmaps

## Applications
- Smart City Traffic Management
- Traffic Prediction
- Traffic Monitoring and Analysis

## Objective
To develop a digital twin based traffic management system for improving traffic analysis and smart transportation solutions.
